# Serial Debugger Project Documentation

Open `../SerialDebugger.lvproj` in LabVIEW. The project uses NI-VISA serial communication and a state-machine design.

The sanitized English guide and a redacted archival Word copy are available at the repository root:

```text
docs/serial-debugger-guide.md
docs/original-materials/SerialDebugger_LegacyGuide_Redacted.docx
```

The original source archive also contained third-party serial utilities, a virtual serial-port installer, activation information, and patch files. Those items are not part of this GitHub repository.
