# Sanitized Original Material

This folder contains a redacted archival copy of the original serial-debugger Word guide. The original document included third-party activation information, which has been removed.

- `SerialDebugger_LegacyGuide_Redacted.docx` - sanitized archival copy in the original language
- `../serial-debugger-guide.md` - English transcription of the useful instructions

The unredacted document and the accompanying third-party installers, credentials, and patch files are not included.
